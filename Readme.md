# 🎓 Student Performance Prediction System

## 📌 Project Overview

The **Student Performance Prediction System** is a web-based application designed to predict and analyze student academic performance.

The project consists of a frontend and backend that work together to provide a user-friendly platform for student performance analysis.

## 🚀 Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Recharts
- jsPDF

### Backend
- Python

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vm9935581-sys/student.git
```

### 2. Open the Project

```bash
cd student
```

### 3. Start the Backend

```bash
cd backend
python app.py
```

### 4. Start the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

### 5. Open in Browser

Visit:

http://localhost:5173/

## ▶️ Run the Complete Project

Windows users can run:

```text
run_all_projects.bat
```

Keep both backend and frontend terminal windows open while using the application.
